시작하기

30초 만에 첫 여행 만들기

Google 계정만 있으면 바로 시작할 수 있어요. 별도 회원가입은 없습니다.

로그인 화면

1. Google로 로그인

표지 화면에서 "Google로 계속하기"를 누르면 끝입니다. 아이디·비밀번호를 새로 만들 필요가 없어요.

2. 새 여행 만들기

로그인하면 내 여행 목록(마이페이지)이 보입니다. "＋ 새 여행 만들기"를 누르면 바로 일정 편집 화면으로 이동해요.

3. 여행 제목과 날짜 입력

맨 위에 여행 제목을 적고, 각 일차 카드에 날짜를 입력하세요. 날짜는 숫자만 입력해도(예: 20260315) 자동으로 정리됩니다.

무료 계정은 여행 3개까지 만들 수 있어요. 이미지 첨부는 여행당 10장까지 가능합니다.

4. 보기모드 / 수정모드

화면 오른쪽 위에서 "보기"와 "수정"을 전환할 수 있어요. 수정모드에서는 모든 내용을 자유롭게 바꿀 수 있고, 보기모드는 조회 전용이라 실수로 내용이 바뀌는 걸 막아줍니다.

5. 자동 저장

입력한 내용은 로그인한 계정에 자동으로 저장됩니다. 저장 버튼을 따로 누를 필요가 없어요.

지금 바로 여행을 계획해보세요

Google 계정으로 30초면 시작할 수 있어요.
