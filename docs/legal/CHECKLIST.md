# 법적 문서 — 런칭 전 채워야 할 항목

세 문서(`terms-ko.md`, `privacy-ko.md`, `ecommerce-ko.md`)는 표준 템플릿을 이 서비스에 맞게 작성한 초안입니다. 아래 항목을 확정·기재하고, 정식 런칭 및 결제 도입 전 법률 전문가 검토를 받으세요.

## 공통 (전 문서)

- [ ] 문의 이메일 — 현재 `[문의 이메일: 추후 제공]`. 전용 주소 확정 후 전 문서 일괄 치환.
- [ ] 시행일 / 공고일 — `[YYYY-MM-DD]` 전부 실제 날짜로.
- [ ] 운영자명 — 개인 운영이면 성명(또는 필명+실명 병기), 사업자면 상호. `[운영자명/개인 또는 상호]`.

## 이용약관 (`terms-ko.md`)

- [ ] 제1조·부칙의 운영자·시행일
- [ ] 제4조3항 유료 기능 도입 여부·시점 (도입 확정 시 문구 조정)
- [ ] 제13조3항 관할 법원 (기본: 민사소송법상 관할. 특정 법원 지정하려면 소비자 거주지 관할 배제 불가 — 약관규제법 유의)

## 개인정보처리방침 (`privacy-ko.md`)

- [ ] 1항 표 — 실제 수집 항목이 코드와 일치하는지 재확인 (현재: 이메일·이름·프로필사진 URL·Google UID / 여행 데이터·이미지·표시설정 / 타임스탬프)
- [ ] 3항 — 장기 미접속 계정 파기/분리보관 기준 확정 (예: 1년)
- [ ] 5항 위탁 표 — Firebase 외 다른 수탁자(분석 도구, 결제 PG 등) 추가 시 표에 반영. 국외이전 고지 문구 법률 검토.
- [ ] 10항 — 개인정보 보호책임자 성명 필수 기재 (법상 필수). 개인 운영이면 운영자 본인.
- [ ] 8항 — 실제 적용 중인 보안조치와 일치하는지 확인 (Firestore 보안 규칙 = "인증된 본인만 자기 문서 접근" 이미 적용됨)

## 유료 서비스 및 환불 정책 (`ecommerce-ko.md`) — 결제 도입 시에만

- [ ] 2항 — 프리미엄 항목·가격·구독주기 확정
- [ ] 3항 — 결제대행사(PG) 확정, 결제정보 처리 흐름을 개인정보처리방침에도 반영
- [ ] 4·5항 — 청약철회 제한 고지·동의 UI를 결제 화면에 실제 구현 (제17조2항)
- [ ] 5항 표 — 구독 중도해지 일할환불/수수료 정책 확정
- [ ] 8항 사업자 정보 — 통신판매업 신고(관할 구청 / 전자상거래 매출 발생 시 의무), 사업자등록, 상호·대표자·주소·전화 전부. 개인 무료 운영 단계에서는 대개 불요하나, 유료 판매 시작 시 필수.

## 배포/노출

- [ ] 표지 하단 + 설정(내 정보 및 옵션)에서 링크 노출
