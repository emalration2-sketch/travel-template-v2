# i18n (English support) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Korean/English language switching to the whole app (UI, landing, share/PDF export, legal docs), with browser-language auto-detection.

**Architecture:** One inline `I18N = { ko:{…}, en:{…} }` dictionary in `index.html` plus `t(key, vars)` for JS-rendered strings and `data-i18n` attributes + `applyI18n(root)` for static markup. `curLang` resolved at boot from `profile.lang` → `localStorage['ttv2-lang']` → `navigator.language` → `'en'`. Changing language re-renders the active screen; no reload. `ko` values are the current literals verbatim (source of truth); missing `en` keys fall back to `ko`.

**Tech Stack:** Vanilla HTML/CSS/JS single file (`index.html`, no build). Firebase compat SDK (auth/firestore). Playwright tests with an injected Firebase stub.

**Spec:** `docs/superpowers/specs/2026-09-09-i18n-english-design.md`

## Global Constraints

- Single file: all code stays in `index.html`. No new JS files, no bundler, no runtime fetch for UI strings. (Legal `.md` docs are the only runtime-fetched text — that already exists.)
- Supported languages this deliverable: `ko`, `en` only. Structure must accept `ja`/`zh` later by adding keys — no other change.
- `ko` dictionary values are copied **verbatim** from the existing literals. Do not reword Korean.
- `console.error(...)` / `console.warn(...)` messages are developer-facing — **do NOT translate them**. Only `alert()`, on-screen text, `placeholder`, `aria-label`, and export output.
- Commit messages end with: `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`
- Work directly on `main` (solo repo, established pattern). After each task: `npx playwright test` must be fully green before commit.
- Deploy check after the final task: `until curl -s "https://emalration2-sketch.github.io/travel-template-v2/index.html?$(date +%s)" | grep -q '<marker>'; do sleep 5; done`

```js
/* ===== i18n ===== */
const LANGS = ['ko','en'];
function detectLang(navLang){
  const b = String(navLang || '').toLowerCase().split('-')[0];
  return LANGS.includes(b) ? b : 'en';
}
let curLang = LANGS.includes(document.documentElement.lang) ? document.documentElement.lang : 'en';
const I18N = { ko: {}, en: {} };   // populated in Task 3
function t(key, vars){
  let s = (I18N[curLang] && I18N[curLang][key]);
  if(s == null) s = (I18N.ko && I18N.ko[key]);
  if(s == null){ if(curLang !== 'ko') try{ console.warn('[i18n] missing key:', key); }catch(e){} return key; }
  if(vars) s = s.replace(/\{(\w+)\}/g, (m, k) => (vars[k] != null ? vars[k] : m));
  return s;
}
function langName(l){ return l === 'en' ? 'English' : '한국어'; }
function applyI18n(root){
  root = root || document;
  root.querySelectorAll('[data-i18n]').forEach(el => { el.textContent = t(el.getAttribute('data-i18n')); });
  root.querySelectorAll('[data-i18n-ph]').forEach(el => { el.setAttribute('placeholder', t(el.getAttribute('data-i18n-ph'))); });
  root.querySelectorAll('[data-i18n-aria]').forEach(el => { el.setAttribute('aria-label', t(el.getAttribute('data-i18n-aria'))); });
}
```
